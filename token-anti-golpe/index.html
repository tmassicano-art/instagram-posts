Token Anti-Golpe

Confirme que é mesmo o seu advogado antes de qualquer pagamento.

Criminosos usam nome, foto e dados de processos de advogados para pedir dinheiro aos clientes. O Token Anti-Golpe dá ao cliente e ao advogado um código de segurança que só os dois conhecem e que muda a cada 30 segundos.

Regra de ouro Quem diz o código é sempre o advogado. O cliente apenas confere na própria tela. Se alguém pedir para você ler o seu código, desligar e "confirmar depois", ou mandar um novo link ou QR Code por mensagem, é golpe.

Como funciona

  1. Vínculo. O advogado cria no painel um vínculo para cada cliente. O sistema gera uma chave secreta exclusiva daquela relação.
  2. Entrega. O cliente aponta a câmera do celular para o QR Code mostrado pelo advogado, de preferência no escritório ou em videochamada. A partir daí, os dois aparelhos passam a mostrar o mesmo código de 6 dígitos.
  3. Conferência. Sempre que receber ligação, mensagem ou pedido em nome do advogado, o cliente pede o código. O advogado lê o número que aparece na tela dele, e o cliente confere se é igual ao da própria tela.
  4. Decisão. Código igual: o contato é autêntico. Código diferente, ou recusa em informar: encerre a conversa e procure o escritório pelos canais que você já conhece.

O código muda a cada 30 segundos e não pode ser descoberto por quem viu o nome do advogado na internet ou leu os autos do processo.

Passo a passo para advogados

  1. Abra o painel do advogado no computador ou no celular do escritório e informe seu nome e número de inscrição na OAB.
  2. Clique em Novo cliente e digite o nome do cliente. Use um nome que você reconheça, como "Maria Souza, inventário".
  3. Mostre o QR Code para o cliente escanear com a câmera do celular. Se ele preferir, pode escanear o QR Code do aplicativo autenticador (Google Authenticator ou Microsoft Authenticator). O QR Code vale por 72 horas.
  4. Peça ao cliente para tocar em Confirmar vínculo e conferir junto com você se o código das duas telas é o mesmo.
  5. Se quiser, imprima a folha de instruções e entregue ao cliente. Ela traz o QR Code e a data de validade.
  6. A cada ligação ou mensagem que envolva pagamento, documentos ou mudança de conta bancária, informe espontaneamente o código atual.
  7. Faça a cópia de segurança do painel e guarde em local protegido. Ela permite usar o painel em outro computador do escritório.

Passo a passo para clientes

  1. No escritório ou em videochamada, aponte a câmera do celular para o QR Code que o advogado mostrar e abra o link.
  2. Confira o nome e o número da OAB do seu advogado e toque em Confirmar vínculo.
  3. Adicione a página à tela inicial do celular para encontrar fácil (no navegador, menu "Adicionar à tela inicial").
  4. Quando alguém falar em nome do advogado, abra o token e peça: "qual é o código?".
  5. Compare o número dito com o da sua tela. Se for igual, pode seguir a conversa. Se não for, encerre o contato.
  6. Se preferir, digite o número no campo Conferir código e o sistema responde se confere.

Perguntas frequentes

Quanto custa?

Nada. A ferramenta é gratuita para advogados e clientes.

Preciso instalar algum aplicativo?

Não. Funciona no navegador do celular ou do computador e pode ser adicionado à tela inicial como um aplicativo, que abre mesmo sem internet. Quem já usa Google Authenticator ou Microsoft Authenticator pode guardar o token lá, pelo segundo QR Code do painel.

Meus dados vão para algum servidor?

Não. Os nomes, os números de OAB e as chaves secretas ficam guardados somente no navegador do aparelho onde foram cadastrados. O código é calculado no próprio aparelho, e as páginas são configuradas para bloquear qualquer envio de dados pela internet.

O código não confere. E agora?

Confira primeiro se você abriu o vínculo do advogado certo e se o relógio do celular está no horário automático. Persistindo a diferença, encerre o contato e ligue para o escritório no número que você já tinha, nunca no número que o desconhecido informou.

Troquei de celular ou apaguei os dados do navegador.

O vínculo se perde junto. Peça ao advogado um novo vínculo, presencialmente ou em videochamada. Desconfie de qualquer novo QR Code ou link enviado por mensagem sem conversa prévia.

Recebi um novo QR Code ou link "do meu advogado" por mensagem.

Não confirme. Se você já tem o token do seu advogado, ele não precisa mandar outro. Trocar o token do cliente é exatamente o que o golpista tenta fazer, para que o código dele passe a "conferir". O sistema avisa quando você já tem token daquele número de OAB. Ligue para o escritório pelo número que você já conhecia.

Por que o QR Code expira?

Para que uma foto ou um encaminhamento do QR Code feito depois da entrega não sirva para criar um token. Ele vale por 72 horas. Depois do vínculo, o código continua funcionando normalmente.

O advogado tem mais de um computador ou uma equipe.

No painel, use Cópia de segurança para baixar o arquivo e Restaurar cópia no outro aparelho. O arquivo contém as chaves dos clientes e deve ser guardado com o mesmo cuidado de uma senha.

Um cliente encerrou o contrato. Como desligo o token dele?

No painel, clique em Excluir no cartão do cliente. O código daquele vínculo deixa de existir no seu aparelho.

Posso ser vítima mesmo usando o token?

O token reduz muito o risco, mas a proteção depende da regra de ouro: quem informa o código é o advogado, e o cliente nunca lê o próprio código para ninguém. Na dúvida, ligue para o escritório pelo número que você já conhecia.

Sofreu ou presenciou uma tentativa de golpe? Registre boletim de ocorrência, avise o advogado pelo contato que você já conhecia e comunique a OAB. Guarde prints, números de telefone e comprovantes.
